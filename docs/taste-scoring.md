# 취향 점수 v1

## 입력 해석과 수치 계산의 분리

기존 `preferences` 자유 입력을 같은 행사 조사 API 요청에서 해석한다. AI는 고정 분류 ID에 대한 `tasteSignals`만 반환하고 점수는 코드에서 계산한다. 별도 유료 요청은 추가하지 않지만 프롬프트와 응답 토큰은 늘어난다.

각 신호는 `axis`(category/subcategory/experience), `id`, `direction`(like/dislike), `quote`(사용자가 입력한 원문 일부)로 구성한다. 서버는 고정 ID와 축의 조합, 원문 포함 여부, 분류 이름 또는 지원 동의어의 존재를 대조한다. 같은 항목의 중복은 한 번만 반영하며 선호·비선호가 상충하면 그 항목은 제외한다.

예: `뷰티는 싫고 방탈출이 좋아요` → 뷰티 비선호, 방탈출 선호. 부정과 비교 표현의 의미 해석은 AI에 의존한다. 원문/ID 검증만으로 모든 문장의 의미가 검증되는 것은 아니다. 모호한 경우 신호를 반환하지 않도록 지시하고, 화면에 '반영한 취향'을 표시해 해석을 확인할 수 있게 한다.

브랜드 선호, 대기·이동·비용·예약·방문 수·시간 요청은 현재 장르 취향 점수에 넣지 않는다. `A보다 B`는 B 선호로 처리하되 A 비선호를 임의로 만들지 않는다. 문장에서 확실하게 추출한 대분류·소분류·태그만 반영하고 관련 분류를 자동 확장하지 않는다. 지원 동의어가 아닌 표현은 보수적으로 누락될 수 있다.

## 행사별 점수

| 일치 항목 | 선호 | 비선호 |
| --- | --- | --- |
| 대분류 | +30 | -30 |
| 소분류 | +50 | -50 |
| 체험 태그 1개 | +20 | -20 |

- 같은 행사의 대분류와 소분류가 모두 일치하면 더 구체적인 소분류만 적용한다. 대분류·소분류 사이의 방향이 달라도 명시적인 소분류를 우선한다.
- 체험 태그는 주제와 독립적으로 더한다. 최종 행사별 합계는 -100~100으로 제한하며 화면에 한도 적용 여부를 표시한다.
- 행사의 분류 출처가 일치한 행사 출처에 포함되는지 다시 확인한다. 분류 미확인은 0점과 `unclassified`로 반환하며 비선호를 뜻하지 않는다.
- 관련 없는 취향은 가감하지 않는다. 취향 입력이 없거나 추출하지 못하면 추가 점수는 0이다. 장르 설명이나 브랜드명만으로 행사 분류를 임의 생성하지 않는다.
- 이 점수는 학습된 만족 확률이나 백분율이 아닌 초기 규칙 기반 가중치다. 실제 사용자 평가로 조정해야 한다.

## 일정 비교에 연결

`DayPlan.score`는 기존 일정 점수 그대로 유지한다. 별도 `tasteScore`는 해당 일정에서 방문하는 행사별 취향 점수의 합이며, `rankingScore = score + tasteScore`로 후보를 비교한다. API 응답에 세 값을 분리해서 제공한다.

취향이 같은 행사 집합의 방문 순서를 바꾸기 위한 지표는 아니다. 같은 행사를 모두 방문하는 일정끼리는 취향 점수가 같고 기존 이동·대기 기준으로 순서를 정한다. 시간 부족 등으로 일부만 방문해야 할 때 취향에 맞는 조합을 고르는 데 영향을 준다.

방문 수의 기존 가중치(장소당 100,000점)와 운영·예약·좌표·시간 검증은 유지한다. 높은 취향 점수로 운영시간이 없는 행사나 미보유 예약을 확정 일정에 넣을 수 없다. 확정 일정과 조건부 일정도 계속 분리한다. 장소별 한도와 최대 세 곳 제약 때문에 취향 합계는 -300~300이다.

방문 목적별 가중치 변경은 아직 적용하지 않았다. '대기를 줄이고 싶다'만 입력했다면 장르 취향 점수는 추가하지 않고 기존 일정 점수로 비교한다.

## 호환성과 확인

- 분류 또는 취향 신호가 없는 과거 응답도 허용하며 취향 가점을 적용하지 않는다.
- 캐시 키에는 기존처럼 취향 원문이 포함된다. 캐시된 조사에서도 현재 시각으로 일정과 취향 점수를 다시 계산한다.
- 화면에는 반영한 취향, 행사별 가감 사유와 점수, 선택 일정의 취향 합계를 표시한다. 출처를 QA에서만 보이는 기존 정책은 유지한다.
- 검증은 모의 조사 응답으로 수행한다. 실제 AI의 문장 해석 정확도나 사용자 만족도는 아직 측정하지 않았다.
